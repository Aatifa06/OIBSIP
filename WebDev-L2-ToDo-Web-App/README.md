# FocusFlow — Motivational To-Do Web App

A feature-rich Task 3 project built with HTML5, CSS3 and Vanilla JavaScript.

## Included
- Animated welcome dashboard
- Rotating daily motivational quotes
- Daily progress tracker
- Growth streak counter
- Editable Dream Board
- Daily Habit Garden
- 25-minute focus timer
- Completion confetti
- Add, edit and delete tasks
- Task search
- High / Medium / Low priority filters
- localStorage persistence
- Responsive desktop/mobile layout
- Light/dark theme toggle
- Friendly empty states

## Run
Open `index.html` with Live Server or directly in a browser.

## Files
index.html — structure
style.css — complete UI and animations
script.js — app functionality, persistence and interactions
README.md — project notes
